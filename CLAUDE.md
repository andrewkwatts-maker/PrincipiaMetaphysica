# PrincipiaMetaphysica
Start with docs/INDEX.md. It lists every live doc with size and status.

Doc layout rules:
- Topic docs stay at 20 KB or less, one area per file. Split at headings.
- docs/OUTSTANDING_ISSUES.md is only an index; open issues live in docs/issues/, closed ones in docs/archive/.
- DECISION_LOG.md keeps the last ~30 entries; older ones go verbatim to docs/archive/DECISION_LOG_older.md.
- Ledgers, generated JSON (AutoGenerated/, docs/issues_index.json) and archive files are grep-only: never Read whole.
- Decisions are written and committed before the result is computed (see DECISION_LOG.md). Archive, don't delete, docs holding decisions.
