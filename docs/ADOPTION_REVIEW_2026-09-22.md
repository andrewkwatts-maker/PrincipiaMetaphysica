**2026-09-22.** A review pass over the `b3_seed = seed_43_joyce` adoption
sweep: what must survive any future cleanup, what a reader should ignore, and
where two artifacts now disagree. Nothing here adopts anything, and no author
ruling is made or implied.

Every number below was MEASURED in this pass by running the code, not copied
from the register. Where a measurement disagrees with the register or with the
directive that commissioned this review, the measurement is stated and the
disagreement is listed in §3.

transients that a rebuild clears". It was not.

| run | result |

| baseline, as inherited | **15 failed, 1997 passed, 846 skipped, 24 errors** (16m12s) |

## 2. THE NOISE — what a reader should ignore, and where it lives

### 2.1 The 846 skips were not a quiet tree (FIXED)

Fifty-three test files and four *source* modules each carried a private copy
of "where is `parameters.json`", every one naming
`H:/Github/PrincipiaMetaphysica` as its non-local candidate. On POSIX that is
a **relative** path — a directory called `H:` under the cwd — so the published
checkout was unreachable by any candidate. Three defects rode along, all
invisible because a missing artifact *skips* rather than fails:

1. the sibling checkout addressed by drive letter, so it never resolved;
2. the order put that path ahead of the repo-local tree — correct on the
   author's machine, wrong everywhere else, with nothing saying which root was
   playing which role;
3. resolution was per-**directory**, so the first root that `is_dir()` won
   whatever it held. Measured: a partial build-scratch tree of 25 artifacts
   shadowing a complete published one of 67, with `formulas.json` at 761 KB
   against 1.69 MB, and a `certificates/` directory holding per-category files
   but none of the per-gate ones — which is how `test_strategy_c_all_pass`
   failed looking for `G01` in a directory that existed and was simply the
   wrong one.

→ `tests/_artifact_search.py` is now the one order, pinned in both directions
by `tests/test_artifact_search_order.py`. Repo-local FIRST among the implicit
roots as directed — safe *only* because resolution is now per-FILE. The four
source-side copies delegate to `core.parameter_artifact`, which already
existed to be that single place.

**Where it went:** `test_artifact_freshness.py` went from 10 skips to 1;
`test_rigor_validator_honesty.py` from fully skipped to 11 tests running
against the real 204-row report. Debt (h) was a consequence of this, not a
separate problem — see §4.

### 2.2 A read path that creates a directory (FIXED)

`generators/_common.autogen_dir()` **mkdirs on a read**. Merely evaluating
gate G32 created an empty repo-local `AutoGenerated/`, which then satisfied
every `is_dir()` candidate check for the rest of the session. G32 also
bypassed its own module's `_params_path()`, skipping the bundled-wheel
fallback that exists so a gate is always scorable.

→ G32 now routes through `_params_path()`. **The mkdir-on-read itself is
unfixed** and listed in §3.

### 2.3 A build that halted on a missing optional extra (FIXED)

`proof_completeness.build_ledger` imports pandas and raises an `ImportError`
*naming* the `plots` extra — a module doing exactly the right thing — but the
step had no row in `OPTIONAL_DEPS`, so nothing caught it and the whole build
stopped. Every later step never ran. That is precisely the failure the comment
beside the gate says must not happen, and that `CLAUDE.md` promises users: *a
missing extra yields an incomplete build, never a failed one.* The rule
existed; the row did not.

**Worse, and worth stating plainly:** a build run without `[sims]` skipped 20+
steps and *still overwrote published artifacts* — it replaced the real 204-row
`validation_report.json` with the placeholder. A degraded build should not be
able to damage a good artifact set. The committed copy was restored from git.

→ `tests/test_build_optional_extras_never_halt.py` now reads each step's own
source for optional imports rather than trusting the map to be complete.

footnote. Re(T) has six incumbent values in the codebase; at 1-in-56 a
near-hit against any of them is expected and means nothing. `B/A` is held
fixed at −0.5 across every pair, because it is the one continuous knob in this
potential and letting it float per row would make this a two-parameter fit
rather than an enumeration of exponent choices.
