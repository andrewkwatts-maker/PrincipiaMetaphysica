# Handoff 2026-10-25: theory paths on the website (D-021)

## What shipped
- **Lineage catalogue** `metaphysica/theories/pm/lineage/branches.yaml`, built from git history
  plus the Downloads documents (archaeology in `docs/plan/paths/archaeology/a1-a3`). Dead
  ends are demoted, never deleted.
- **Paths page** `Pages/paths.html` has two views: lineage (theory versions over time) and
  switches (engine forks and options). Main (the D-015 active path) is highlighted.
  Selecting a path shows why it was adopted, considered or rejected, plus what worked
  and what failed.
- **Path overlay**: `?path=<fork>--<option>` patches every page's AutoGenerated JSON with
  RFC 6902 ops, pinned to the published file's sha256. A sticky bar says these are the
  path's results, not predictions, with Why and Return to main path. A sha mismatch is
  refused, and the page shows main with a notice. Contracts: `docs/plan/paths/contracts.md`.
- **Engine**:
  - `build.py --keep-going` writes `build_status.json`.
  - Steps that run in-process now print UTF-8.
  - `paths-publish` takes several twin builds, plus the theory's declared stochastic subtrees.
  - The `n_gen` guard refuses non-three seeds with a reason.

sequentially, because the AutoGenerated junction is shared. Then:
`python -m metaphysica.testground paths-publish --theory pm --main-run <site> --volatile-run
<fast main A> <fast main B> --runs <runs> --published <site> --out <site>/AutoGenerated/paths`
