#### THE BASELINE DID NOT REPRODUCE, AND THE REASON WAS A MISSING INPUT WEARING A RESULT

The handover pinned **2266 passed / 393 skipped / 0 failed** at `9368b5f`.
Measured from a clean container at that exact commit: **1796 / 848 / 16
failed**, 18m43s. Installing the `[full]` extras (`arithma`, `eml-spectral`,
`matplotlib`, `xhtml2pdf` — all of which *do* install here, contrary to the
twenty-second pass's note about `[pdf]`) fixed exactly one. Running
`python -m metaphysica.build --out ./site` first, as this register already
requires, fixed none of the remaining fifteen.

The root cause is one line, and it had been load-bearing for a long time:

```python
Path(__file__).resolve().parents[3] / "AutoGenerated" / "parameters.json"
```

`parents[3]` is **`src/`**, a directory the build never writes to. So the first
candidate could never match on any machine, and the only remaining candidate
that could was `H:/Github/PrincipiaMetaphysica/AutoGenerated/parameters.json`
— an absolute path from the author's Windows machine. Off that machine
`free_set._params()` returned an **empty dict**.

Nothing raised. Every verification below it reported `available: False`, no row
was removed, and `free_set_size` came out equal to `ledger_rows`. Five tests
then failed with messages about the *physics* — "the reduction is inert",
"unclassified rows need a reading", "an error bar is not a free parameter" —
while the actual fault was a path. This is the most expensive defect shape in
the tree: **a missing INPUT presenting as a RESULT**, and it is the third time
this campaign has met it.

`b3_path._registry` carried a second, differently-broken copy of the same
lookup (CWD-relative plus the same Windows path), so every registry
cross-check it fed had been silently skipping.

Fixed by extracting **one** resolver, `core/parameter_artifact.py`, which both
now call: `METAPHYSICA_OUT` → repo root → `site/AutoGenerated` → the sibling
`PrincipiaMetaphysica` checkout → the author's path → CWD-relative. It returns
the rows **with their provenance**, and the unavailable case carries its own
explanation. `build_free_set` now reports `reduction_ran` and
`parameters_source`, so an unreachable artifact can never again read as a
closed free set.

The bundled wheel snapshot `metaphysica/data/parameters.json` is deliberately
**not** a fallback: measured, it carries **620 of the 808** built rows and
**111 shared rows hold different values**. Falling back to it would feed stale
numbers into a reduction that reports itself as verified.

**With the lookup fixed, the free set is 37 of 67 rows** (11
DERIVED_ARITHMETIC + 11 DUPLICATE + 8 NOT_A_MODEL_KNOB removed) and the
closure ledger classifies all 37 with **nothing UNCLASSIFIED**:

| layer | rows |
|---|---|
| TOPOLOGICAL | 0 |
| METRIC_DEPENDENT | 7 |
| FLAVOUR | 13 |
| FLUX_DEPENDENT | 2 |
| EXPERIMENTAL + DISCRETE_CHOICE (not knobs) | 15 |

Those are exactly the numbers the handover carried, which is the cross-check

Broken, the same report gave 67 rows with 9 UNCLASSIFIED.

#### TASK 7a — THE GLUED FORM CROSSES A DEGENERATE WALL. It does NOT cross over.

The orbit/degeneracy scan is built (`PM/geometry/glued_orbit_scan.py`) and the
measured outcome is the **second** of the three the charter listed:
**DEGENERATE**, and specifically **not** CROSSOVER.

The distinction turned on getting the invariant right, and it is worth pinning
because the wrong reading was one line away and would have rewritten the
wording task. Under φ → A\*φ, Hitchin's bilinear transforms as
**B → (det A) Aᵀ B A**. Two different things follow:

* the **GL(7,ℝ) orbit** invariant is the signature **up to overall sign** — an
  orientation-reversing *A* flips *B*. The compact orbit is the unordered pair
  {7,0}; the split orbit is {4,3}. **(4,3) and (3,4) are the same orbit.**
* the **sign of det B** is invariant only under GL⁺(7,ℝ), and on a manifold
  with a fixed orientation it is meaningful.

Measured over 700 grid points (one family, r/a ∈ [1,100], t ∈ [0,100], seven
θ):

* the unordered signature is **{4,3} at every single point**. The glued form
  **never leaves the split orbit**. There is no crossover, so the two
  `g2_form_convention` branches do **not** differ by region, and Task 1's
  wording is unchanged by this.
* det B nevertheless **changes sign**. **165 of 700** points carry ordered
  signature (3,4) rather than (4,3) — an orientation flip *inside* the one
  orbit — so a locus with **det B = 0 must lie between them**. 36 sign changes
  in r were bracketed. Had the classifier read the *ordered* signature it
  would have reported a crossover to the compact orbit, which would have been
  false.

**Where the wall is.** Bisecting geometrically in r, the wall sits at a fixed
value of one dimensionless combination:

| t | r\*/a | t·a²/r\*² |
|---|---|---|
| 1 | 1.1180 | 0.8000 |
| 2 | 1.5221 | 0.8633 |
| 5 | 2.3191 | 0.9297 |
| 10 | 3.2172 | 0.9662 |
| 100 | 9.8900 | 1.0224 |
| 1000 | 31.1109 | 1.0332 |

So **r\* ∝ √t**, approaching **t·a²/r\*² → 1**. That was *predicted from the
form and not fitted to the scan*: η's leading radial behaviour is a²/r², so
the twisted block's amplitude relative to the flat block is t·a²/r² and a wall
at fixed amplitude must sit at r\* ∝ √t. **The wall is where the twisted block's
amplitude equals the flat block's.** The residual below 1 is the subleading
a⁴/r⁴ term in η, which dies as the wall moves outward — hence the monotone
approach.

**There is a critical amplitude, and below it the wall is off the manifold.**
The neck begins at the bolt r = a, so a wall at r\* < a is not in the geometry.
Measured t_crit by θ:

| θ | 0⁺ | π/6 | π/4 | π/3 | π/2 | 2π/3 | π⁻ |
|---|---|---|---|---|---|---|---|
| t_crit | 2.2247 | 0.9824 | 0.7743 | 0.6403 | 0.4766 | 0.3903 | 0.4082 |

Largest at the pole, where η's cos θ component is extremal and its sin θ
component vanishes. **For t below t_crit(θ) the glued form is a stable 3-form
of the split orbit on the entire neck.** So this is not a claim that the
construction is broken; it is a claim about an **amplitude**, and the amplitude
has a measured threshold of order one.

**What it does mean.** The framework now has a locus, generated by its own
gluing rather than put in by hand, on which φ is **not stable and no metric is
induced at all**. Every metric-dependent statement on the neck acquires a
domain of validity, r > r\*(t, θ), which nothing previously carried. This is the
first dynamically-generated singular structure in the framework.

Everything above is **leading-order-in-t**, and the flat block is written in
the neck chart through the **asymptotic (ALE)** identification of the four
moved coordinates with the four Eguchi–Hanson axes. Both tags are attached to
every record the module returns, not stated once here. It is the orbit of the
leading-order glued form, not of the exact Joyce metric, which the framework
does not have.

A fork-aware seam guard is in place: at r = a with t **below** t_crit, Hitchin's
B must carry exactly the fork's declared negative-eigenvalue count (3 on split,
0 on compact), read from `geometry_narration.holonomy_claim` rather than
hardcoded. It is placed below t_crit deliberately — a guard at t = 1 would sit
*inside* the wall, where the ordered count legitimately reads 4, and would fail
against the real geometry.

#### TASK 2 — REFUTED: nothing is unpaired, because the map is TOTAL

The claim was that 3 flat 3-forms pair with the singular involutions and **4
are left unpaired**, matching the 4 free involutions.

A map exists, and it refutes the claim by being a **bijection**. Measured over
the live enumeration: each of the 7 non-identity elements of Γ has a fixed set,
and **all 7 of those fixed sets are invariant 3-forms**, injectively and onto.
**Nothing is left unpaired.**

So the 4 is real and **the reason given for it is wrong**. The four forms the
claim calls unpaired are precisely the four **paired with the free
involutions**. "7 = 3 + 4" is *one* partition — singular versus free, on the
involution side — transported across a bijection that was already there.
Reading it as two independent counts agreeing is counting the same split twice.

The bijection is not itself a coincidence: both sides are indexed by the same
third object. φ's support is the 7 lines of PG(2,2), the Γ-invariant 3-forms
*are* those lines (R3/R5), and each non-identity element fixes exactly one. The
map is **form → Fano line → element**, and both legs are forced by φ.

**What is canonical and what is not.** The bijection depends only on φ. The
3 + 4 split does not: **24 distinct singular triples** occur among the first
4001 admissible assignments scanned. "These particular four flat forms" names a
**choice of half-shift**, not a property of the geometry, so no argument may
attach physics to a specific four.

A4 bar, per arrow: invariant 3-form = a COHOMOLOGY CLASS; Fano line = a LINE of
PG(2,2); involution = a GROUP ELEMENT; singular/free = a property of an element
**under an assignment**, not of the element alone. The bijection is a
correspondence of INDEX SETS, not an identification of the objects indexed.

#### TASK 6 — the silent default was in FOUR modules, not one

`geometry_narration._resolve` caught bare `Exception` and returned a hardcoded
branch. `variants.resolve` raises **KeyError** for an undeclared fork and
**ValueError** for an unknown option, so both were swallowed: a renamed fork
would have left the module narrating `all_plus_one` while its docstring
promised a live read — a silent default in the module written to abolish silent
defaults.

An AST sweep found the same shape in three more places. The most serious was
not the one reported:

* **`b3_path.n_gen_report`** — the `n_gen_source` override block, whose entire

* **`preferred_path._invalidate_caches`** — a stale cache surviving a switch

All narrowed to **ImportError only** — the one condition a fallback was ever
meant for. Even that is no longer silent: it is recorded in
`fork_reads_degraded()` and surfaced by `narrate()` as `all_reads_were_live`,

#### TASK 7b — FLUX FREEZES ONE MODULUS, AND IT IS NOT A LEDGER ROW

`PM/geometry/flux_quantization.py` builds W = Σ n_I Π_I on the 43 basis with
Π_I := K_II from the leading-order pairing. The structural measurement decides
the whole question before any flux vector is chosen:

> **At leading order K_IJ is diagonal with exactly two distinct entries —
> L⁷/8 on the 7 flat classes, 32π²L³ on the 36 twisted ones — and its ONLY
> free symbol is L. `t` does not appear.**

The twenty-second pass already supplied the reason: ‖η_EH‖² = 8π² *exactly* for
every bolt radius, because in four dimensions the L² norm of a 2-form is
invariant under g → t²g. The twisted sector's whole t-dependence sits in the T³
volume and the 1-form legs, and at leading order that leaves L alone.

Three consequences, all measured:

* **43 integers collapse to 2.** W sees n only through A = Σ_flat n_I and
  B = Σ_twisted n_I. Any claim that a particular 43-vector does something a
  different vector with the same (A, B) does not is false at this order.
* **dW/dL = 0 has a positive root iff A and B have opposite signs**, at
  L\*⁴ = −768π²B/(7A), and it is a minimum there. 8 of the 25 (A, B) pairs in
  the box |A|,|B| ≤ 2 qualify. This is **stationarity of W**, not a vacuum: a
  vacuum needs the Kähler potential and its derivatives, which the framework
  does not have. Every key in the module says `stationarity_of_W` and none
  says `vacuum`.
* **No ledger row is frozen.** The 7 METRIC_DEPENDENT rows are moduli VEVs and
  quantities built from them — t-like, and t is absent. The 2 FLUX_DEPENDENT
  rows additionally need threshold data. L itself is not a ledger row.

**So the continuous count stays at 22.** The null is structural, not unfinished
work, and it carries the condition that would overturn it: the **O(t²)
cross-blocks**, which `block_structure` already reports as an order. Not more
