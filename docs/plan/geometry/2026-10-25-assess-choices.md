## Contract: option assessment (B)
- Per fork, the active option plus each alternative, scored as follows:
  - **P:** Δpass, Δfail and Δχ² from `paths/<id>/summary.json`. The state is INVALID (with the refusal reason from `index.json` `not_computed`), INERT, or COMPUTED.
  - **R:** for the parameters the option changes (the path `patch.json` ops on `parameters.json`), the counts by registry status. provable_share = (GEOMETRIC + DERIVED) / changed.
  - **E:** the change in free-variable count where the ledger can attribute it (OPEN otherwise), plus the unexplained literals summed from the formula audit.
  - **T:** true if the option removes a CALIBRATED or FITTED parameter or a free variable and Δfail ≤ 0.
  - **guard:** the rows behind ΔP whose audit class is C24 or H. Those are subtracted from P before dominance and listed as "fit at 24".
  - **candidate:** the D-026 dominance rule, after the guard.
- The assessment is regenerated after paths-publish. Missing inputs print OPEN, never a guess.
