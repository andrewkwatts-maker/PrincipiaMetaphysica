## Verification rules (in publish)
- Round-trip: `apply(main_fast, ops) == path_fast` with volatile keys masked, for each file.
  On a failure, that path goes to `not_computed` with the reason.
- Published base: when `sha256(P file) != sha256(M file)`, check each op against P (for
  replace and remove the value at the pointer equals M's value; for add the parent
  exists). If a file fails, drop it from the patch and list it in
  `summary.unverified_files` (add that key, a list, empty by default).
- Files: every `*.json` under `AutoGenerated/` recursively, except `paths/**` and
  `path_graph.json`. Exact equality, no float rounding.
