## Principle
A single-option deviation can be **incoherent**, because forks are coupled (for example
seed_19 with `n_gen_source=b2_over_faces` gives n_gen = 1). The engine already refuses
those early with a `ValueError` that states the reason. That refusal is a result, and
the site shows it as "why this path does not work". A **crash** (ZeroDivisionError,
KeyError, ...) is a generalisation defect: fix it so the path either computes or is
refused early with a clear reason. Never make an incoherent path "work" by
special-casing values.
