## Build `src/metaphysica/testground/audit/` (one concept per file, ≤ 200 lines each)
Types: `Selection = Mapping[str, str]` (fork → option; a missing fork means its default).
`Rows = Mapping[str, Any]`. `Option = Tuple[str, str]`.
1. `rows.py`: `differs(a, b)` and `changed(base, other) -> FrozenSet[str]`, ported verbatim
   (rel 1e-12, NaN equals NaN, exact for non-numbers); `load_rows(run_root)` reading
   `AutoGenerated/parameters.json` → `{key: value}`, or `None` when it is absent.
2. `classes.py`: `equivalence_classes(runs: Mapping[str, Rows]) -> List[RunClass]`.
   `RunClass(representative, members)`: a run joins the first class whose representative
   it does not differ from on any row. Classes come in input order and members in input order.
   Document in one line that the tolerance is not transitive, which is why each run is
   compared with the representative.
3. `noop.py`: `no_op_options(base: Rows, singles: Mapping[Option, Rows]) -> List[Option]`,
   the single deviations that change no row.
4. `interactions.py`:
   - `footprints(base, singles) -> Dict[Option, FrozenSet[str]]`;
   - `interaction_sets(footprints, *, k_max=3, compatible=lambda sel: True, limit=10_000)`:
     every set of 2..k_max options from distinct forks that pairwise share a row and are
     `compatible`, as sorted tuples in a deterministic order. Assert `2 <= k_max <= 4`.
     Raise a ValueError naming the count when `limit` is exceeded;
   - `predict(base, singles, selection) -> Dict[str, FrozenSet]` gives the allowed values
     per row: the baseline where no chosen option changed the row, that option's value
     where one did, and any of their values where several did (the current precedence rule);
   - `non_additive(base, singles, selection, joint_rows) -> List[str]` lists the rows whose
     joint value is not allowed. It must give the same answers as `interactions.py` on its
     pair cases; port those tests.
5. `sampling.py`: `sample_selections(forks, n, *, seed, canonical=lambda s: dict(s),
   compatible=lambda s: True, statuses=("active","considered"), max_tries=100*n)`.
   Each fork picks uniformly among options with those statuses (`random.Random(seed)`).
   The all-default selection is excluded, results are deduped by
   `json.dumps(canonical(s), sort_keys=True)`, and the output is ordered and deterministic.
   It raises with the count when it can't find n.
6. `reads.py`: `reconcile_reads(forks, runs, *, gate_open=lambda fork_id, sel: True)`,
   where `runs: Mapping[run_id, Tuple[Selection, Mapping[str, int]]]` holds a selection and
   its reads per fork. It returns a `ReadFindings` with `never_read` (forks unread in every run),
   `undeclared_gates` ((fork, run_id) pairs that are unread there although `gate_open`), and
   `closed_gate_reads` ((fork, run_id) pairs read although the gate is closed).
7. `report.py`: `audit(...)` assembles the above into one plain dict with sorted keys (a
   JSON-ready contract), plus `to_markdown(report)` with one short table per finding kind.
   Write the dict shape into `PrincipiaMetaphysica/docs/plan/paths/contracts.md` as a new
   last section, "§N Path audit", following the existing style.

## Tests: `tests/testground/test_audit_*.py`, deterministic and synthetic
Cover each function, including:
- a coincidence (two different selections, identical rows → one class);
- a gate (fork B unread when A=x → an undeclared gate; read → a closed-gate read once
  `gate_open` says closed);
- a 3-way interaction that pairs alone don't flag in `predict`;
- sampling determinism (same seed → same list);
- limit and k_max errors;
- one test using the toy theory's forks (`metaphysica.theories.toy`) for `sample_selections`.
- Acceptance: the new tests pass; `tests/testground` passes as before (run it first in the
  background as the baseline); the AST dependency test passes.
