# Brief S1: rank the paths, consistency first, fit breaks ties (2026-10-28)

Owner direction: select the path dynamically from the best output. The rank is lexicographic:
consistent, then fewest ladder failures, then fewest applicable gate failures, then lowest χ²
(the tie-break). The contract is in `track_s_selection.md`.

## Work
1. Add `metaphysica.testground` ranking (`testground/rank.py` and a `rank` CLI subcommand):
   `python -m metaphysica.testground rank --theory pm --runs-dir DIR --out FILE`. It reads each
   run's result and published rows and writes `path_ranking.json` to the contract.
   - Keep it generic. The theory declares how to read consistency, ladder, gates and anchors
     (as `Stage.rows_written` did). Test on the toy theory.
   - **Consistency:** the `switch_search` verdict for the run's selection.
   - **Ladder:** the master-action ladder checks the build publishes (`metaphysica.actions`, L1/L2).
   - **Gates:** `gates.total_failed` and `gates.total_passed` (G1 makes these path-relative later;
     read whatever the run has).
   - **χ²:** rows that carry an experimental value and σ. Find the existing field, for example
     the anchor groups and `observable_groups`. Exclude INPUT, CALIBRATED and CALIBRATION_CHECK
     rows. List any input a run lacks under `missing`; never guess it.
   - **reasonable:** consistent, ladder_failed ≤ the selected path's, and Δχ² ≤ 4. Make the 4 a
     named constant.
2. The rule text changes from "never rank" to "rank by consistency first, fit breaks ties,
   disclose the selection and the number searched". This is in the `switch_search.py`
   docstring and the variants rule (find it in `simulations/core/variants/`). Update any test
   that pins the old wording.
3. Run it on the completed runs in `H:/claude-scratch/p5a/runs` (the sweep is still running;
   read only, using the runs that finished). Write the result to
   `src/metaphysica/data/path_ranking.json` in W, and add a build step that publishes it to
   `AutoGenerated/path_ranking.json`. If the file is absent, the step skips with a logged line.
4. Don't change the default selection. That is S2, later.
