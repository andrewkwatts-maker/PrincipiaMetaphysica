## 2. Falsifiability record (physical observables only)
- TESTED_NOW: value, experimental value, uncertainty and sigma, with PASS / TENSION / FAIL as
  recorded.
- TESTABLE: a named experiment, its projected sensitivity, and the value that would kill it.
  Link each of the 6 kill switches to its registry id and check that the numbers agree.
- UNFALSIFIABLE: neither, with the reason.
- **Circularity flag:** a PREDICTED/DERIVED row whose chain contains its own experimental datum,
  or a CALIBRATED/FITTED row that is scored as a PASS against the datum it was set from. That is
  a retrodiction, not a test.
